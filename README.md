# UPI Transactions & Digital Payments Analytics

## 📌 Project Overview

This project analyzes UPI and digital payment transaction data to identify transaction trends, payment behavior, merchant patterns, and fraudulent transactions.

## 🛠️ Tools & Technologies

* Python
* SQL
* Power BI
* DAX
* Data Visualization

## 🎯 Objectives

* Analyze overall transaction performance
* Identify transaction trends over time
* Analyze transaction types and merchant categories
* Study transaction success and failure rates
* Identify fraudulent transactions
* Analyze transaction behavior across different states, banks, devices, and networks
* Create an interactive Power BI dashboard

## 📊 Key Analysis

The project includes analysis of:

* Total transactions
* Total transaction amount
* Average transaction value
* Transaction status
* Transaction type
* Merchant category
* Fraud transactions
* Monthly transaction trends
* State-wise transaction patterns
* Device and network analysis
